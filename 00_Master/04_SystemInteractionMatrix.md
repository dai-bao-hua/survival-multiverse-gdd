# System Interaction Matrix

| 系统 | 影响 | 被影响 |
|---|---|---|
| 行动 | 时间、探索、资源 | 状态、天气、特征 |
| 生存状态 | 可选行动、死亡风险 | 食物、水、天气、事件 |
| 地图迷雾 | 可见路线 | 探索、线索、Flag |
| 事件 | 状态、物品、Flag、路线 | 地点、天气、NPC、Seed |
| Flag | 后续事件与结局 | 选择、关键物、NPC |
| 天气 | 行动成本、事件权重 | 世界规则、Day |
| NPC | 路线、物品、信息 | 信任、帮助、欺骗 |
| 结局 | 本局终止 | 路线完成度、Flag、状态 |
