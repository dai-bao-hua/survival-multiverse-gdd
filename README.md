# Survival Multiverse GDD

这是一个面向 TapTap 的 **2D 多世界生存命运模拟器** GDD 仓库。

荒岛只是第一个世界。后续世界可以是极寒冰原、火山群岛、隔离区、死亡荒漠、沉没世界、永夜森林、实验世界等。

## 核心原则

- 游戏形态：2D 节点式生存决策游戏，不做 3D，不做实时自由移动。
- 核心体验：迷雾、未知、选择、资源压力、事件链、路线交叉、多结局。
- 世界：底层系统共享，不同世界必须改变规则，不能只是换皮。
- 路线：任何主要结局都必须经过多阶段，不允许几次点击直接通关。
- 死亡：允许中途死亡；普通死亡时每局最多 3 次激励广告复活。
- 重开：一局结束后，无论随机新局还是相同 Seed 重开，复活次数恢复为 3。
- 结局死亡：真正的失败结局/主动终局不走广告复活。
- 素材：正式美术素材统一由用户自己的素材 MCP 生成。
- 平台：面向 TapTap，移动端优先。
- 架构：数据驱动，事件、选项、Flag、路线、世界规则尽量配置化。

## 从哪里开始

1. 先读 `00_Master/00_GDD_Master.md`
2. 再读 `00_Master/01_GameVision.md`
3. 开发系统时读 `01_CoreSystems/`
4. 做某个世界时读 `03_Worlds/<World>/`
5. 做素材时读 `08_Art/`
6. 做 TapTap/Maker 开发时读 `09_Technical/`
7. 每完成阶段更新 `PROJECT_STATUS.md`

## 目录

- `05_NumericalDesign/`：数值
- `06_Monetization/`：广告与商业化
- `07_UI_UX/`：界面交互

- `09_Technical/`：技术实现
- `10_Production/`：开发阶段
- `11_QA/`：测试与逻辑审计
